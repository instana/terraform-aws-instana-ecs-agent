# Examples

This directory contains example configurations for using the Instana AWS Sensor ECS module.

## Available Examples

### [Basic Example](./basic/)
A minimal example for deploying the sensor with a new ECS cluster and security group.

### [Complete Example](./complete/)
A more complete example showing configurable options such as existing resources and public or private subnet deployment.

## Usage

Refer to the example directories for sample Terraform configurations.
Copy the example that best matches your use case and update the variable values for your environment.
